# PayFlow v0.4.0

Esta versão introduz o primeiro fluxo assíncrono completo do PayFlow sem transformar a aplicação em
microserviços nem colocar Kafka no caminho crítico da transferência.

## Destaques

- `TransferCompleted.v1` gravado por outbox na mesma transação financeira;
- Kafka local opcional e relay com tentativas persistidas e limitadas;
- auditoria deduplicada dentro do monólito;
- duas retentativas no consumidor e dead-letter topic para falhas persistentes;
- retenção de sete dias para outbox publicada e mensagens Kafka;
- métricas e correlação dos logs do fluxo assíncrono.

## Fluxo desta candidata

1. a versão `0.4.0` é estabilizada na branch `release/0.4.0`;
2. o mesmo commit é publicado temporariamente em homologação;
3. após a validação, a candidata segue por Pull Request para `main`;
4. o workflow de release cria a tag anotada `v0.4.0` e o GitHub Release;
5. produção publica exclusivamente a revisão identificada pela tag.

## Executar localmente

Ambiente comum, sem Kafka:

```bash
docker compose up --build
```

Ambiente de estudo com Kafka, relay e auditoria:

```bash
docker compose -f compose.yaml -f compose.events.yaml up --build --wait
```

Abra <http://localhost:5173>. A documentação da API fica em
<http://localhost:8080/swagger-ui.html> e as métricas internas em
<http://localhost:8080/actuator/metrics>.

## Aviso

O PayFlow é um projeto de portfólio. Todas as contas e quantias são fictícias e nenhuma operação
movimenta dinheiro real. Kafka permanece opcional e não é publicado na AWS nesta versão.
