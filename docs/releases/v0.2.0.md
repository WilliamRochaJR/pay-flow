# PayFlow v0.2.0

Esta versão evolui a publicação efêmera da PoC para um fluxo profissional de promoção por ambientes,
mantendo a mesma aplicação e a infraestrutura reproduzível.

## Destaques

- promoção controlada entre `development`, `homologation` e `production`;
- infraestrutura e identidades AWS isoladas por ambiente;
- autenticação dos workflows por GitHub OIDC, sem chaves AWS persistentes;
- deploy de desenvolvimento pela branch `develop` e de homologação por `release/*`;
- revisão de produção vinculada a uma tag anotada e imutável;
- branches de release protegidas por Pull Request e checks obrigatórios;
- deploy efêmero de desenvolvimento validado e removido depois do teste.

## Fluxo desta candidata

1. a versão `0.2.0` é estabilizada na branch `release/0.2.0`;
2. o mesmo commit é publicado temporariamente em homologação;
3. após a validação, a candidata segue por Pull Request para `main`;
4. o workflow de release cria a tag anotada `v0.2.0` e o GitHub Release;
5. produção publica exclusivamente a revisão identificada pela tag.

## Executar localmente

```bash
docker compose up --build
```

Abra <http://localhost:5173>. A documentação da API fica em
<http://localhost:8080/swagger-ui.html>.

## Aviso

O PayFlow é um projeto de portfólio. Todas as contas e quantias são fictícias e nenhuma operação
movimenta dinheiro real.
