# PayFlow v0.3.0

Esta versão fortalece o fluxo de transferências e introduz a primeira camada de métricas de negócio e
alarmes de infraestrutura da PoC.

## Destaques

- histórico de transferências paginado, ordenado e filtrável por período e status;
- proteção e testes de concorrência com PostgreSQL real;
- métricas Micrometer para resultado e duração das transferências;
- métricas administrativas acessíveis pelo Actuator sem exposição pelo proxy público;
- alarmes CloudWatch efêmeros para falha de status da EC2 e CPU elevada;
- infraestrutura, alarmes e aplicação removidos pelo mesmo TTL.

## Fluxo desta candidata

1. a versão `0.3.0` é estabilizada na branch `release/0.3.0`;
2. o mesmo commit é publicado temporariamente em homologação;
3. após a validação, a candidata segue por Pull Request para `main`;
4. o workflow de release cria a tag anotada `v0.3.0` e o GitHub Release;
5. produção publica exclusivamente a revisão identificada pela tag.

## Executar localmente

```bash
docker compose up --build
```

Abra <http://localhost:5173>. A documentação da API fica em
<http://localhost:8080/swagger-ui.html>.

As métricas internas podem ser consultadas em <http://localhost:8080/actuator/metrics>.

## Aviso

O PayFlow é um projeto de portfólio. Todas as contas e quantias são fictícias e nenhuma operação
movimenta dinheiro real.
