# PayFlow v0.1.0

Primeiro release público da PoC PayFlow, demonstrando um fluxo financeiro fictício completo do React
ao PostgreSQL e sua publicação efêmera na AWS.

## Destaques

- cadastro e login com Spring Security, BCrypt e JWT;
- contas isoladas por usuário e transferência atômica com validação de saldo;
- idempotência para impedir transferências duplicadas;
- dashboard React responsivo com histórico e rotas protegidas;
- testes unitários, integração, componentes e E2E;
- cobertura e Quality Gate do SonarQube Cloud;
- Swagger/OpenAPI, logs estruturados, correlation ID, health checks e rate limiting;
- Docker Compose para desenvolvimento e produção;
- Terraform, GitHub OIDC e deploy AWS efêmero com TTL e limpeza automática;
- Git Flow, branches protegidas e processo de release versionado.

## Executar localmente

```bash
docker compose up --build
```

Abra <http://localhost:5173>. A documentação da API fica em
<http://localhost:8080/swagger-ui.html>.

## Aviso

O PayFlow é um projeto de portfólio. Todas as contas e quantias são fictícias e nenhuma operação
movimenta dinheiro real.
