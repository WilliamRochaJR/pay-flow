# PayFlow v0.5.0

Esta versão introduz estorno integral como uma nova transferência imutável, preservando a operação
original e mantendo PostgreSQL como fonte de verdade dos saldos.

## Destaques

- endpoint idempotente de estorno com proteção transacional e concorrente;
- vínculo pesquisável entre estorno e transferência original;
- evento `TransferReversed.v1` gravado atomicamente na outbox e projetado na auditoria;
- dashboard com confirmação, feedback e atualização dos saldos e do histórico;
- métricas de conclusão, repetição, rejeição, falha e duração dos estornos;
- contrato OpenAPI com respostas do caso de uso;
- E2E em Chromium cobrindo cadastro, login, transferência e estorno.

## Fluxo da candidata

1. a candidata nasce na branch `release/0.5.0` a partir do M5.1 integrado em `develop`;
2. Maven, projeto raiz, front-end e lockfiles declaram a versão `0.5.0`;
3. publicar temporariamente a mesma revisão em homologação;
4. promover a candidata por Pull Request para `main` após aprovação;
5. criar a tag anotada `v0.5.0` e o GitHub Release somente depois dos checks em `main`.

## Executar localmente

```bash
docker compose up --build
```

Abra <http://localhost:5173>. A documentação da API fica em
<http://localhost:8080/swagger-ui.html> e as métricas internas em
<http://localhost:8080/actuator/metrics>.

## Aviso

O PayFlow é um projeto de portfólio. Todas as contas e quantias são fictícias e nenhuma operação
movimenta dinheiro real. O estorno não representa integração com uma instituição financeira.
